## Step 7 — Business rules

For each rule, give: an ID, the rule in business terms, conditions and outcome, where it is implemented (program and paragraph or procedure), the data involved, whether it is explicit in the code or inferred, and an example (input and expected result) that could be used to verify the same rule in the target system.

Format the result so it can be published as-is to a wiki page such as Confluence (headings, one table per functional topic). Do not propose a target implementation.
