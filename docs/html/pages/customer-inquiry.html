Customer Inquiry

The Customer Inquiry function provides complete personal and demographic data retrieval for policyholders within the General Insurance Application (GenApp). It is implemented as a multi-tier CICS/DB2 flow consisting of an application-layer orchestrator (LGICUS01) and a dedicated database retrieval module (LGICDB01). The entry point validates the incoming request, inspects runtime routing controls to determine the target channel, and delegates the query to the DB2 data layer to fetch customer details into a shared communication area (COMMAREA).

1. Overview

The customer inquiry transaction coordinates data retrieval between caller interfaces (such as CICS BMS 3270 terminal menus or web services) and the DB2 relational database.

  • Business Logic Entry Point (LGICUS01): Validates the incoming CICS COMMAREA, performs safety checks against buffer lengths, checks a CICS Temporary Storage (TS) queue for alternate routing flags (MQHIT=), and links to the appropriate backend service.
  • Database Access Module (LGICDB01): Receives the inquiry request from the orchestrator, converts the 10-digit customer number into a binary integer, queries the CUSTOMER table in DB2, populates the COMMAREA with customer details, and handles database status codes (SQLCODE).
  • Error and Diagnostic Subsystem (LGSTSQ): Serves as a centralized diagnostic program that receives timestamped error records and raw COMMAREA snapshots for logging to CICS Transient Data Queues (TDQ) when failures occur.

2. System Architecture

The architecture separates routing and business orchestration from relational database access. The caller invokes LGICUS01 via EXEC CICS LINK, passing a standard 32,500-byte COMMAREA. LGICUS01 queries the Temporary Storage queue GENAWMQC to inspect runtime control flags. In standard operational mode, it delegates the inquiry to LGICDB01 to execute embedded SQL against the DB2 CUSTOMER table.

4. Program Specifications

4.1 Orchestrator Program: LGICUS01

LGICUS01 acts as the business routing controller for customer inquiries:

  1. Task and Context Capture: Captures EIBTRNID, EIBTRMID, and EIBTASKN into WS_HEADER for diagnostic context.
  2. Buffer Guard Checks:
    • If EIBCALEN = 0, logs " NO COMMAREA RECEIVED" to LGSTSQ and terminates with EXEC CICS ABEND ABCODE('LGCA') NODUMP.
    • Calculates minimum length: WS_REQUIRED_CA_LEN = WS_CUSTOMER_LEN (72) + WS_CA_HEADERTRAILER_LEN (18) = 90 bytes. If EIBCALEN < 90, sets CA_RETURN_CODE = '98' and returns immediately.
  3. Queue-Based Route Detection:
    • Issues EXEC CICS READQ TS QUEUE('GENAWMQC') ITEM(1) into MQ_READ_RECORD.
    • If response is DFHRESP(NORMAL), sequentially scans records using READQ TS ... NEXT.
    • If SUBSTR(MQ_READ_RECORD, 1, 6) = 'MQHIT=', sets MQ_HIT = 1.
  4. Downstream Dispatch:
    • If MQ_HIT = 0: Invokes EXEC CICS LINK PROGRAM('LGICDB01') COMMAREA(COMM_AREA) LENGTH(32500).
    • If MQ_HIT = 1: Invokes EXEC CICS LINK PROGRAM('AAAAAAAA') COMMAREA(COMM_AREA) LENGTH(32500).

4.2 Database Access Program: LGICDB01

LGICDB01 executes the relational data access against DB2:

  1. Validation & Conversion: Validates EIBCALEN ≥ 90. Converts CA_CUSTOMER_NUM (defined as PIC '9999999999') into the binary integer host variable DB2_CUSTOMERNUMBER_INT (FIXED BIN(31)).
  2. Database Query: Executes a singleton SQL query fetching personal and contact details directly into COMMAREA fields.
  3. Return Code Mapping:
    • SQLCODE = 0: Success (CA_RETURN_CODE = '00').
    • SQLCODE = 100 (Not Found) or SQLCODE = -913 (Deadlock / Timeout): Maps to CA_RETURN_CODE = '01'.
    • Any other SQLCODE: Maps to CA_RETURN_CODE = '90', triggers WRITE_ERROR_MESSAGE to log to LGSTSQ, and returns control.

6. Implementation Code Examples

6.1 COMMAREA Validation and Routing Logic (LGICUS01)

PLI 
/* Validate COMMAREA presence */
IF ( EIBCALEN = 0 ) THEN DO;
    EM_MSG_TEXT = ' NO COMMAREA RECEIVED';
    CALL WRITE_ERROR_MESSAGE;
    EXEC CICS ABEND ABCODE('LGCA') NODUMP;
END;

CA_RETURN_CODE = '00';
CA_NUM_POLICIES = 0;

/* Check Minimum Required COMMAREA Length (90 bytes) */
WS_REQUIRED_CA_LEN = WS_CUSTOMER_LEN + WS_CA_HEADERTRAILER_LEN;
IF ( EIBCALEN < WS_REQUIRED_CA_LEN ) THEN DO;
    CA_RETURN_CODE = '98';
    EXEC CICS RETURN;
END;

/* Inspect Temporary Storage Queue for MQ routing override */
GET_CUSTOMER_INFO: PROCEDURE;
    MQ_HIT = 0;
    EXEC CICS READQ TS QUEUE(MQ_CONTROL) INTO(MQ_READ_RECORD)
              RESP(WS_RESP) ITEM(1);
              
    IF ( WS_RESP = DFHRESP(NORMAL) ) THEN DO;
        DO UNTIL ( WS_RESP > 0 );
            IF ( WS_RESP = DFHRESP(NORMAL) &
                 SUBSTR(MQ_READ_RECORD, 1, 6) = 'MQHIT=' ) THEN DO;
                MQ_HIT = 1;
            END;
            EXEC CICS READQ TS QUEUE(MQ_CONTROL) INTO(MQ_READ_RECORD)
                      RESP(WS_RESP) NEXT;
        END;
    END;

    IF ( MQ_HIT = 0 ) THEN DO;
        EXEC CICS LINK PROGRAM('LGICDB01')
                  COMMAREA(COMM_AREA)
                  LENGTH(32500);
    END;
    ELSE DO;
        EXEC CICS LINK PROGRAM('AAAAAAAA')
                  COMMAREA(COMM_AREA)
                  LENGTH(32500);
    END;
END GET_CUSTOMER_INFO;

6.2 DB2 Query and Status Handling (LGICDB01)

PLI 
/* Convert Picture Decimal to Integer Host Variable */
DB2_CUSTOMERNUMBER_INT = CA_CUSTOMER_NUM;
EM_CUSNUM = CA_CUSTOMER_NUM;

/* Execute Singleton SELECT against CUSTOMER table */
GET_CUSTOMER_INFO: PROCEDURE;
    EM_SQLREQ = ' SELECT CUSTOMER';
    
    EXEC SQL
        SELECT FIRSTNAME,
               LASTNAME,
               DATEOFBIRTH,
               HOUSENAME,
               HOUSENUMBER,
               POSTCODE,
               PHONEMOBILE,
               PHONEHOME,
               EMAILADDRESS
        INTO   :CA_FIRST_NAME,
               :CA_LAST_NAME,
               :CA_DOB,
               :CA_HOUSE_NAME,
               :CA_HOUSE_NUM,
               :CA_POSTCODE,
               :CA_PHONE_MOBILE,
               :CA_PHONE_HOME,
               :CA_EMAIL_ADDRESS
        FROM   CUSTOMER
        WHERE  CUSTOMERNUMBER = :DB2_CUSTOMERNUMBER_INT;

    /* Evaluate SQLCODE outcome */
    SELECT (SQLCODE);
        WHEN (0) DO;
            CA_RETURN_CODE = '00';
        END;
        WHEN (100, -913) DO;
            CA_RETURN_CODE = '01';
        END;
        OTHERWISE DO;
            CA_RETURN_CODE = '90';
            CALL WRITE_ERROR_MESSAGE;
            EXEC CICS RETURN;
        END;
    END;
END GET_CUSTOMER_INFO;

6.3 Diagnostic Logging Procedure (WRITE_ERROR_MESSAGE)

PLI 
WRITE_ERROR_MESSAGE: PROCEDURE;
    EM_SQLRC = SQLCODE;
    
    EXEC CICS ASKTIME ABSTIME(WS_ABSTIME);
    EXEC CICS FORMATTIME ABSTIME(WS_ABSTIME)
              MMDDYYYY(WS_DATE)
              TIME(WS_TIME);
              
    EM_DATE = WS_DATE;
    EM_TIME = WS_TIME;

    /* Write structured diagnostic record to LGSTSQ */
    EXEC CICS LINK PROGRAM('LGSTSQ')
              COMMAREA(ERROR_MSG)
              LENGTH(STG(ERROR_MSG));

    /* Dump raw incoming COMMAREA payload up to 90 bytes */
    IF ( EIBCALEN > 0 ) THEN DO;
        IF ( EIBCALEN < 91 ) THEN DO;
            CA_DATA = LEFT(COMM_AREA_RAW, EIBCALEN);
        END;
        ELSE DO;
            CA_DATA = LEFT(COMM_AREA_RAW, 90);
        END;
        
        EXEC CICS LINK PROGRAM('LGSTSQ')
                  COMMAREA(CA_ERROR_MSG)
                  LENGTH(STG(CA_ERROR_MSG));
    END;
END WRITE_ERROR_MESSAGE;

7. Error Handling and Status Codes

The Customer Inquiry flow enforces structured error management across invocation, routing, and database retrieval.

Condition / Error Return Code System Action Diagnostic Outcome
Successful Inquiry CA_RETURN_CODE = '00' Normal return (EXEC CICS RETURN) Demographic fields populated in COMMAREA
Missing COMMAREA (EIBCALEN = 0) N/A EXEC CICS ABEND ABCODE('LGCA') NODUMP Message "NO COMMAREA RECEIVED" written to LGSTSQ
COMMAREA Too Short (EIBCALEN < 90) CA_RETURN_CODE = '98' Immediate EXEC CICS RETURN Processing halted; no DB2 call or logging
Customer Not Found (SQLCODE = 100) CA_RETURN_CODE = '01' Normal return (EXEC CICS RETURN) Output fields unpopulated; no error log
DB2 Deadlock / Timeout (SQLCODE = -913) CA_RETURN_CODE = '01' Normal return (EXEC CICS RETURN) Treated cleanly as record unavailable
Unexpected DB2 Failure (e.g., SQLCODE < 0) CA_RETURN_CODE = '90' Immediate EXEC CICS RETURN Full ERROR_MSG and 90-byte COMMAREA dump logged via LGSTSQ
