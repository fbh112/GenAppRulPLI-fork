Diagnostics, Error Logging & Operational Telemetry

1. Overview

The GenApp insurance application implements a layered diagnostics, error-logging, and operational telemetry architecture built entirely on CICS primitives. Rather than relying on external logging frameworks, the application uses four dedicated PL/I programs — each with a distinct and complementary role — to provide end-to-end observability across the CICS region:

  • LGSTSQ is the centralized error message logging utility, accepting text messages from any calling program or directly from a terminal operator and persisting them to both the CICS system log (CSMT TDQ) and an application-level Temporary Storage Queue (GENAERRS or a dynamically routed GENAnnnn).
